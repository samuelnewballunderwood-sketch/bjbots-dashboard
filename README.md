# AlphaControl Dashboard

Live trading bot dashboard at [alphacontrol.ai](https://alphacontrol.ai) (legacy [bjbots.ai](https://bjbots.ai) 301-redirects here).

## Making Updates

1. Edit `dashboard.html` for UI/display changes
2. Edit `worker.js` for API/backend changes
3. Commit to `main` branch — auto-deploys to alphacontrol.ai in ~30 seconds
